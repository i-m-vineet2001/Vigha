## 🌹 About

**Vigha** is a personal digital love story built for **Vineet × Megha**.

It is designed as more than just a website — it is a small digital world where memories, photographs, letters, dreams, and promises can live together.

The website follows our story through different sections, from our first moments together to the memories we want to keep and the future we imagine.

---

## ✨ Features

- 💕 Romantic interactive landing page
- 📸 Memories & photographs
- 📝 Personal love letter
- 💌 Open When messages
- 🎵 Romantic music player
- 🕰️ Relationship timeline
- 🧠 Interactive relationship quiz
- 🌙 Future dreams & bucket list
- 💖 Final surprise / reveal
- 🖼️ Image lightbox
- ✨ Floating particles and romantic animations
- 🪞 Glassmorphism UI
- 🌊 Animated wavy backgrounds
- 📱 Responsive design for mobile and desktop
- 💾 Local browser storage for added memories
